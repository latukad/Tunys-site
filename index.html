Local-first creator tooling

Create. Review. Publish.
From one local studio.

TUNYS KI Studio is a desktop-based workflow for creating original AI-assisted video content, reviewing output, and managing authorized YouTube actions for the project owner. The software is designed around local processing, explicit account authorization, and private-first publishing.

Learn how it works Read the privacy policy

Original content workflow

TUNYS helps prepare original videos using local AI and creator-controlled source material.

Private-first YouTube upload

Authorized uploads are created as private first so they can be checked before any later status change.

Local account credentials

OAuth credentials and refresh tokens used by the desktop application are stored on the user's own computer.

Google / YouTube integration

What the YouTube connection is used for

When the project owner explicitly connects a Google account, TUNYS uses the granted YouTube permissions to read relevant channel/video status, upload videos as private, verify processing state, and update publishing status or scheduling when requested by the user.

1
Authorize
The user grants access through Google's OAuth consent flow.
2
Create & review
Content is generated locally and passes project quality checks.
3
Upload privately
The YouTube upload starts in private status.
4
Publish only when authorized
Any later status or scheduling action is performed through the connected account and its granted permissions.
TUNYS does not sell Google user data, does not use Google user data for advertising, and does not expose OAuth tokens on this website. Users can revoke Google access and remove locally stored OAuth credentials; details are in the Privacy Policy.
