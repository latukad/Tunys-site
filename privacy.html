Privacy Policy

Last updated: 22 September 2026

This Privacy Policy explains how TUNYS KI Studio ("TUNYS", "the application") accesses, uses, stores, and shares information when a user connects a Google / YouTube account. TUNYS is a local desktop application intended for the project owner and authorized users.

1. Data accessed from Google / YouTube

Depending on the permissions granted by the user, TUNYS may access:

  • basic YouTube channel and video metadata needed to identify the connected channel and verify video state;
  • video upload functionality for user-authorized uploads;
  • video status information such as privacy state, processing state, and scheduled publication information;
  • permissions needed to update video status or scheduling when the user requests those actions.

2. How Google user data is used

Google user data is used only to provide the connected YouTube features of TUNYS, including reading relevant channel/video state, uploading user-authorized videos as private, verifying processing, and updating publishing status or scheduling when requested.

3. Storage

OAuth credentials, access tokens, refresh tokens, and TUNYS runtime data used by the desktop application are stored locally on the user's computer. They are not published by this website and TUNYS does not keep a separate cloud copy of those local OAuth tokens.

4. Sharing and selling

TUNYS does not sell Google user data. TUNYS does not share Google user data with advertisers or data brokers. Data is not used for personalized advertising. Data may be processed by Google/YouTube as required to perform the API actions initiated through the connected account.

5. Limited Use

TUNYS's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

6. Revoking access and deleting local credentials

A user can revoke TUNYS access at any time from the Google Account settings for third-party connections. After access has been revoked, the user can remove the local OAuth token/credential files used by the TUNYS installation. Because these credentials are stored locally, deleting the local files removes TUNYS's retained authentication data from that computer.

For help with revocation, local credential deletion, or a privacy request, contact latukad@gmail.com.

7. Website hosting

This public information website does not use TUNYS analytics, advertising trackers, or marketing cookies. It is hosted using GitHub Pages. GitHub may process technical request information such as IP addresses for security and service operation under GitHub's own privacy practices.

8. Data retention

TUNYS retains local authentication and runtime data only as needed for the user's authorized workflow. Users can revoke Google access and remove locally stored authentication data when they no longer want the integration. TUNYS does not retain a separate cloud copy of local OAuth tokens.

9. Changes to this policy

This policy may be updated when TUNYS functionality or Google API usage changes. The current version will always be published on this page with an updated revision date.

10. Contact

Privacy, authorization, and data-deletion questions can be sent to latukad@gmail.com.
